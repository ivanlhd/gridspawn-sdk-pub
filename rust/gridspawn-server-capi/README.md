# gridspawn-server-capi

C ABI for [`gridspawn-server`](../gridspawn-server): Gridspawn's server SDK
for C, C++ and Unreal. Server-side only. Linux is built and tested; other
platforms are not yet.

Status: 0.3.0, source only. Licence: MIT OR Apache-2.0 (see the end of this
file). ABI version 1 (`GS_ABI_VERSION`). The rules are the preamble of
`include/gridspawn_server.h`.

## Build

From the public SDK repository (https://github.com/ivanlhd/gridspawn-sdk-pub), where this crate sits next to
`gridspawn-server` under `rust/`:

```sh
git clone https://github.com/ivanlhd/gridspawn-sdk-pub && cd gridspawn-sdk-pub/rust/gridspawn-server-capi
cargo build --release      # target/release/libgridspawn_server_capi.{a,so}
```

Inside the Gridspawn monorepo, the same commands run in
`sdk/rust/gridspawn-server-capi`. Pin a commit for reproducible builds.

Header: `include/gridspawn_server.h` (generated by cbindgen; the test
`tests/header.rs` fails when it is stale; `GS_UPDATE_HEADER=1 cargo test --test header`
rewrites it).

Linking the static library on Linux also needs `-lpthread -ldl -lm -lrt` (the
set the tests use); `cargo rustc --lib --crate-type staticlib -- --print native-static-libs`
prints the full list for your toolchain.

## Example

`examples/c/club_post.c` posts to your game's club:

```sh
cc -std=c99 examples/c/club_post.c -Iinclude target/release/libgridspawn_server_capi.a \
   -lpthread -ldl -lm -lrt -o club_post
GRIDSPAWN_APP_ID=game-… GRIDSPAWN_ENVIRONMENT=development \
GRIDSPAWN_CREDENTIAL_FILE=/path/to/0600-key-file ./club_post patch-notes
```

## Voice rules (who hears whom)

The same rules as `gridspawn-server`'s `session.voice()` (its README has the
details: rooms, the player state that must come first, positions, limits):

```c
GsVoiceAck ack;
gs_voice_configure(session, "{\"rooms\": {\"match\": {\"mode\": \"channels\"}}}", &ack, &error);

GsVoicePlayerState state;
gs_voice_player_state_init(&state);              /* alive, may speak, every room */
const char *channels[] = {"team:red"};
state.channels = channels; state.channels_len = 1;
gs_voice_set_player_state(session, player_id, &state, &ack, &error);  /* before the voice ticket */

GsVoicePublisher *positions;
gs_voice_publisher_spawn(session, 10, &positions, &error);
gs_voice_publisher_update(positions, player_id, x, y, z, yaw, true, &error);  /* every tick; 2D: (x, 0, y) */
gs_voice_mute(session, player_id, true, NULL, &error);
gs_voice_publisher_free(positions);
```

- `gs_voice_configure` takes the configuration as JSON in its wire shape and
  checks it before sending.
- `GsVoiceAck.enforced` is false until the first player of the session joins
  voice. That is not an error.
- Errors: `GS_ERROR_CODE_VOICE_*`, plus `gs_error_field` and
  `gs_error_reason` for invalid bodies.
- `gs_voice_publisher_last_error` returns the last batch's failure (free it
  with `gs_error_free`).

## Live game data for your club

The same as `gridspawn-server`'s `client.game()` (its README has the
details: one writer per key, TTLs, limits). No game session is needed.
**Club pages are public: publish display names only, never emails or ids.**

```c
GsDataAck *ack;
gs_game_data_set(client, "match.score", "{\"red\": 3, \"blue\": 1}", 0, &ack, &error);
gs_data_ack_free(ack);
gs_game_data_set(client, "lobby.open", "true", 300, NULL, &error);   /* TTL 300 s */
gs_game_data_remove(client, "lobby.open", NULL, &error);

GsDataEntry set[] = {{"match.round", "4", 0}};
const char *removes[] = {"lobby.banner"};
gs_game_data_set_many(client, set, 1, removes, 1, NULL, &error);    /* 1-40 entries */

GsDataPublisher *live;
gs_game_data_publisher_spawn(client, 4, &live, &error);              /* 1-5 Hz */
gs_game_data_publisher_set(live, "match.clock", "812", 0, &error);   /* every frame */
gs_game_data_publisher_free(live);

char *event_id;
gs_game_event_emit(client, "match.ended", "{\"winner\": \"Red team\"}", NULL, &event_id, NULL, &error);
gs_string_free(event_id);
```

- Values are JSON text, parsed and checked before sending. `ttl_seconds` 0
  means no TTL; otherwise 10–86400.
- `GsDataAck`: `gs_data_ack_accepted_len` / `_key`, `gs_data_ack_skipped_len`
  / `_key` / `_seq` (keys another writer owns) and `gs_data_ack_quota`.
- `gs_game_event_emit` with `id` NULL generates the Idempotency-Key; pass
  your own (`[A-Za-z0-9_-]{8,64}`) for an event that may be sent again after
  a restart.
- `gs_game_data_list` returns the writer's listing as JSON (free it with
  `gs_string_free`). It is for start-up and checks, not for polling.
- Errors: `GS_ERROR_CODE_GAME_DATA_*`. `gs_error_reason` is
  `"personal_data"` when an email or a Gridspawn id was found, and
  `gs_error_field` holds the JSON path.
- `gs_game_data_publisher_skipped_json` and
  `gs_game_data_publisher_last_error` report what the publisher could not
  send.

## Rules in short

- Fallible functions return `GsStatus`. The last parameter, `GsError **`, may
  be NULL; free errors with `gs_error_free`.
- `gs_client_connect` consumes the credential. `char **` outputs are freed with
  `gs_string_free`, which zeroizes them. Every `gs_*_free` accepts NULL.
- Handles are thread-safe. Each client owns a 2-worker runtime.
- `gs_post_async` calls its callback once, on a worker thread. Never call
  blocking `gs_*` functions from the callback: they are refused.
- Panics never cross into C (`GS_STATUS_INTERNAL`), with the default
  `panic = "unwind"`.
- Check `gs_abi_version() == GS_ABI_VERSION` before use.
